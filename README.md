# 模型路由对照实验

用同一组多轮任务比较固定模型和分级路由。这个 Python 工具记录答复、调用与成本，导出按会话匿名化的评审材料。模型调用和评分由实验者完成。

## 一次实验的汇总

实验覆盖 10 个主题、30 道题、90 份答复。每种策略回答同一套题，满分均为 300。这里公开策略级得分和估算积分。

| 策略 | 总分 | 估算积分 |
| --- | ---: | ---: |
| 固定高档（`high`） | 299.5 / 300 | 8.864 |
| 固定中档（`mid`） | 299.5 / 300 | 1.652 |
| 分级路由（`route`） | 297.5 / 300 | 1.666 |

在这组题上，中档与高档同分，积分估算低约 81.4%。路由比中档少 2 分，积分估算多 0.014。在自己的任务上比较时，可同时记录固定中档和路由所需的全部调用。以上积分均为估算，实验没有真实账单。此公开版包含两组全新虚构示例，可用于复跑流程。公开内容未包含 WorkBuddy 的真实数据。

## 快速开始

使用 Python 3.9 或更新版本，无需安装第三方包。从项目目录运行下列命令，实验产物保存在临时目录中。

```sh
scratch="$(mktemp -d)"
python3 bench.py init --out "$scratch/run"
python3 bench.py next --out "$scratch/run" --arm mid
python3 bench.py meta --arm mid > "$scratch/meta.json"
```

从你使用的平台取得答复，将原文保存为 UTF-8 文本，并把实际调用和证据填入元数据。完整命令见 [CLI.md](CLI.md)。路由规则和反馈记忆示例见 [ROUTING.md](ROUTING.md)。

## 复现实验方法

1. 固定题库、回合顺序、上下文配置、模型版本和评分标准。要复现汇总实验的规模，可以在自己生成的题库中设置 10 个主题，每个主题连续问三题，并比较 `high`、`mid` 和 `route` 三种策略。
2. 每个主题在每种策略下单独开始会话。同一主题的后续回合带上该策略此前生成的答复。记录实际调用，以及分类、直答、重试和失败产生的开销。
3. 使用 CLI 导出匿名评审材料。先独立评分并固定结果，再用私有映射汇总到各策略。可预设每题 10 分，并在开始前确定事实准确性、约束满足和上下文承接等评分细则及失败的处理方式。
4. 分别汇总得分、失败数、估算积分及账单能够确认的实际支付。以相同单位、渠道和估算方法比较各策略。公布汇总发现时保留样本规模和估算口径。

CLI 默认还提供固定低档，`pack` 完整导出要求填齐启用的策略。如只比较三种策略，可用 `pack --partial` 导出，并按导出的覆盖率确认哪些策略有完整数据。
