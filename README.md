# 对话中的自适应模型路由器

同一份周报里，核算金额、解释差异、把结论写成三句话，对模型的要求各不相同。这个项目让轻量模型先判断每一轮，在能完成时直接作答；有必要时再把工作交给更合适的模型。它还能利用下一轮的纠正，调整以后同类工作的选档。

先按运行指南绑定三个实际模型。以下示例使用虚构材料。第二条命令复用第一条的本地会话。

```sh
python3 dialogue.py --session demo --family weekly-report '观察组完成了 18/20 件，对照组完成了 16/20 件。写一句给周会的摘要。'
python3 dialogue.py --session demo --family weekly-report '再列出两组分别的完成率。'
```

普通追问会带上前文继续回答。若用户明确指出某一步用了错误的分母，系统会尝试把反馈关联到上一轮实际执行的阶段。过往证据会影响后续同类任务；模型仍须对当前回合重新初判。

对话模式把原文保存在使用者设备上，并把最近三轮随新问题发给配置的模型服务。单次调用可以使用 `router.py`。使用不同的本地状态目录隔离使用者或客户；输入中仅放允许发送给该模型服务的材料。

在配置服务之前，可先运行离线回归测试，观察代码能否按预期选择模型和更新状态。测试固定模型返回，用于检查编排逻辑。

```sh
python3 -m unittest discover -v
```
